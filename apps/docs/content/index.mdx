<Flow
  eyebrow="How it works"
  title="From controller to docs site in three steps"
  description="No second source of truth. The docs read your Nest app the way Swagger does, then build a site you own."
  align="center"
>
  <FlowStep icon="code" title="Describe your API">
    Use the `@nestjs/swagger` decorators you already have, or add OrbitDocs extras for samples, errors and notes.
  </FlowStep>
  <FlowStep icon="scan-search" title="Extract the spec">
    `orbitdocs extract` boots your module in Nest's preview mode. No provider starts, so no database or queue is touched.
  </FlowStep>
  <FlowStep icon="rocket" title="Ship the site">
    `orbitdocs build` writes a static site for any host, or serve it from your own Nest app with private docs and Ask AI.
  </FlowStep>
</Flow>
