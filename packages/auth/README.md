# @orbitdocs/auth

Private docs for OrbitDocs: single sign-on (Google, Microsoft Entra ID, Okta, Auth0, Clerk, Keycloak), reuse of your product's session, access rules and the request handlers for Nest, Next and edge runtimes.

Configured under `access` in `orbitdocs.config.ts`.

Part of [OrbitDocs](https://github.com/VitraAI/OrbitDocs): open-source API documentation for NestJS,
with a Scalar-style reference, MDX guides, an API client, private docs, Ask AI and SDKs. The npm
packages are released together, so install the same version of each.
