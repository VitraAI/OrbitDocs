<Callout title="Rate limits">
  Each API key or access token can make **60 requests per minute**; every response
  carries `X-RateLimit-Limit`, `X-RateLimit-Remaining` and `X-RateLimit-Reset`. Over
  the limit you get `429` with a `Retry-After` header; wait that many seconds before retrying.
</Callout>
